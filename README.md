# Online Store Database

 

This project is a simple online store database designed to manage customers, products, orders, and payments.

 

## Features:

- **Customers** table: Stores customer information.

- **Products** table: Stores product details including price and stock.

- **Orders** and **OrderDetails** tables: Manage orders placed by customers and the products in each order.

- **Payments** table: Keeps track of payments made for orders.

 

## SQL Queries:

- Query 1: Get all orders placed by a customer.

- Query 2: Calculate total revenue from all orders.

- Query 3: Find the most popular product.

 

## How to Run:

1. Import the SQL file into your MySQL or PostgreSQL database.

2. Run the queries from the SQL file to populate the database with sample data.

3. Execute the queries to get results.
